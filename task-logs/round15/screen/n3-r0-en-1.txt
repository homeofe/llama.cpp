### Difference Between a Process and a Thread

To understand the difference, we must look at how an operating system manages resources and execution.

#### 1. Process
A **process** is an instance of a computer program that is being executed. It is the fundamental unit of resource allocation.
*   **Isolation:** Each process has its own private memory space (heap, stack, data segments). If one process crashes, it generally does not affect other processes.
*   **Overhead:** Creating and switching between processes is expensive because the OS must manage separate memory maps, page tables, and kernel structures.
*   **Communication:** Processes communicate via Inter-Process Communication (IPC) mechanisms like pipes, sockets, or shared memory, which require explicit synchronization and data copying.

#### 2. Thread
A **thread** is the smallest unit of execution within a process. A process can have multiple threads.
*   **Shared Resources:** Threads within the same process share the same memory space (heap, global variables, file descriptors). Each thread has its own stack and register state.
*   **Lightweight:** Creating and switching between threads is much faster and consumes less memory than processes because they share the same address space.
