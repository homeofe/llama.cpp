### Difference Between a Process and a Thread

To understand the difference, it helps to visualize them in terms of **isolation** and **resource sharing**.

#### 1. Process
A **process** is an independent instance of a program in execution. It is the fundamental unit of resource allocation in an operating system.

*   **Memory Space:** Each process has its own **isolated memory space** (heap, stack, data segments). One process cannot directly access the memory of another.
*   **Overhead:** Creating and switching between processes is **expensive** because the OS must manage separate memory maps, page tables, and context switches.
*   **Communication:** Inter-Process Communication (IPC) is required (e.g., pipes, sockets, shared memory) and is relatively slow.
*   **Stability:** If one process crashes, it does **not** affect other processes. This is called **fault isolation**.
