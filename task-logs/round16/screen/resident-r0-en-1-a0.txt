### Difference Between a Process and a Thread

To understand the difference, it helps to view them through the lens of operating system resource management.

#### 1. Process
A **process** is an instance of a computer program that is being executed. It is the fundamental unit of resource allocation.
*   **Isolation:** Each process has its own independent memory space (heap, stack, data segments). If one process crashes, it generally does not affect other processes.
*   **Overhead:** Creating and switching between processes is expensive because the OS must manage separate memory maps and context switches are heavier.
*   **Communication:** Processes communicate via Inter-Process Communication (IPC) mechanisms like pipes, sockets, or shared memory, which require explicit synchronization.

#### 2. Thread
A **thread** is the smallest unit of execution within a process. A process can contain multiple threads.
*   **Shared Resources:** Threads within the same process share the same memory space (heap, global variables, file descriptors). Each thread has its own stack and register state.
*   **Lightweight:** Creating and switching between threads is much faster and consumes less memory than processes.
*   **Communication:** Threads communicate easily by reading/writing shared memory
