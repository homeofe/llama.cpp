### Difference Between a Process and a Thread

To understand the difference, it helps to visualize them in terms of **isolation** and **resource sharing**.

#### 1. Process
A **process** is an independent instance of a computer program that is being executed.
*   **Isolation:** Each process has its own **private memory space** (heap, stack, code segment). If one process crashes, it does not affect other processes.
*   **Overhead:** Creating and switching between processes is **expensive** because the operating system must manage separate memory maps and context switches.
*   **Communication:** Processes communicate via **Inter-Process Communication (IPC)** mechanisms (e.g., pipes, sockets, shared memory), which are slower and more complex.

#### 2. Thread
A **thread** is the smallest unit of execution within a process. Multiple threads can exist within a single process.
*   **Sharing:** Threads within the same process **share the same memory space** (heap, global variables, file descriptors). Each thread has its own stack and register state.
*   **Overhead:** Creating and switching between threads is **lightweight** and faster than processes because less context needs to be saved/restored.
