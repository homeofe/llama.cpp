### Difference Between a Process and a Thread

To understand the difference, it helps to visualize them in terms of **memory isolation** and **resource sharing**.

#### 1. Process
A **process** is an independent instance of a program in execution.
- **Memory Space:** Each process has its own **isolated memory space** (heap, stack, code segment). One process cannot directly access the memory of another.
- **Overhead:** Creating and switching between processes is **expensive** because the OS must manage separate memory maps, page tables, and context switches.
- **Isolation:** If one process crashes, it does not affect other processes. This provides high stability.
- **Communication:** Processes communicate via **Inter-Process Communication (IPC)** mechanisms (pipes, sockets, shared memory), which are slower and more complex.

#### 2. Thread
A **thread** is the smallest unit of execution within a process.
- **Memory Space:** Threads within the same process **share the same memory space** (heap, global variables, code segment). Each thread has its own stack and registers.
- **Overhead:** Creating and switching between threads is **lightweight** because they share the same address space. Context
